# 🎯 - Record an Instance of Flow state

The purpose of this feature is to capture information about when and what you were listening to when you achieved your flow state.  AI has been useful to generate the markdown files.


## Assumptions

- Capturing the flow state will be hard to do because when we are in the flow we oftentimes do not realize that we are in the flow.
- There will be access to an AI agent to generate out the markdown file.
- The AI agent will be able to get information from the given url.

## Current Workflow

1. The user copies the template from the docs folder.
2. The user fills out the template at the appropriate folder/files for the given song.
3. The user adds their song to the list of songs.
4. The user creates a merge request into the base repository with their additions.


## Ideas

- Perhaps the interface is an url, and from there an agent creates a markdown file in the appropriate place with the appropriate information.
